# Architectural Assets Platform Redesign

Source: Figma file `vSUSqIvNq6ZtmWxHk1mn8W`, page `1-5`, frame
`4231:502` (`work detail-Architectural Assets Platform Redesign`).

Assets were exported from the design and retain their original resolution.
The case study is implemented as selectable, bilingual HTML in `project1.html`,
with isolated styling and reveal animations in `architecture-detail.css` and
`architecture-detail.js`. No other project's shared stylesheet was changed.

`architecture-background.js` positions the eight original Figma glow layers
against chapter anchors and scales them uniformly from the 1440px reference.
The four `glow-*.svg` exports retain the original paint, opacity and blur.
`background.svg` remains the no-script / failed-asset fallback.

The desktop composition follows the 1440 px frame. Narrow layouts reflow the
same content into stacked sections; they are responsive adaptations, not a
separate mobile Figma frame. The project period is 2023–2024 as shown in this
revision. Existing list metadata was not changed.

Hero, comparison and page-gallery images intentionally use clipped windows,
matching the design. The original source images remain available here.
