# Portfolio delivery checks

- This site deploys to Cloudflare Pages. `.html` links are redirected to extensionless URLs. Never infer page identity solely with `endsWith('.html')`; declare essential page classes in HTML and support clean URLs.
- Use the Cloudflare-style preview (`node scripts/cloudflare-preview.mjs --port 4175`) for user-facing previews, not only a generic static server.
- Before handing off website changes, run `scripts/check-site.mjs` with the available Playwright runtime and fix failures. It covers every root HTML page, all Work List tabs, desktop/mobile, direct entry/refresh, language, browser history, headers/footers, project pagination, media and local asset failures.
- Also retain the dedicated `scripts/check-deployment-paths.mjs` regression for detail identity and typography. Do not claim production is verified if online access was unavailable: distinguish local deployment simulation from real CDN testing.
- Run `scripts/check-navigation-stall.mjs` and `scripts/check-project-entry.mjs` when changing navigation/loading. All Home covers, Work List covers and project pagination links must use the same canonical destination per project. Shared loading feedback may observe native navigation but must never cancel/delay it, capture input, or remain visible indefinitely. Its CSS must fail open independently of JavaScript timers. Test paused animation callbacks and delayed responses as well as fast navigation.
- Update local CSS/JS content hashes and all relevant navigation entry versions together. Check `git diff --check`. Do not commit or push without the user's request.
- Preserve design and original detail image quality. Do not turn editable headings/metadata into screenshots to hide layout bugs.
- Mobile detail pages use the shared app/work detail Show more header and touch pagination. Architecture uses app/work detail-Architectural; Research, Cozyup and Materials retain their dedicated Figma mobile body compositions. Chatbot and OKR use their existing 1084px Web presentation canvases, scaled into a 16px-gutter mobile column (345px at a 377px viewport), with proportionally scaled 24px Web slide gaps; never scale their outer Web shell. Other case-study artwork uses the 1440px Web composition scaled uniformly. Pagination must stay outside the scaled artwork. Run `scripts/check-mobile-detail-scale.mjs` and `scripts/check-mobile-detail-ui.mjs` after changing detail layouts, including rotation back to desktop. Keep original editable text and original image sources.
